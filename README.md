# Backrooms Escape - APK project (no permissions, fully offline, ~50 MB)

The app bundles an "HD pack" generated by tools/gen_assets.py: 25 HD textures + normal maps (5 level designs),
5 music tracks (one per level design) and ~50 sound effects. Everything is created locally - no downloads at runtime.
Expected APK size: about 50 MB.

## Option A - build the APK online (no PC needed)
1. Create a free GitHub account and a new repository.
2. Upload ALL files of this project (keep the .github and tools folders).
3. Open the "Actions" tab -> "Build APK" -> wait ~8-10 min -> download the artifact "backrooms-apk" (zip containing app-release.apk).
   The workflow generates the HD pack, downloads three.min.js and signs the APK with app/release.jks.

## Option B - Android Studio
1. pip install numpy scipy pillow
2. python3 tools/gen_assets.py app/src/main/assets/hd 90      (about 1-2 minutes)
3. Download https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js -> app/src/main/assets/three.min.js
4. Open the folder in Android Studio -> Build -> Build APK(s) (or: gradle assembleRelease).

Change the keystore password in app/build.gradle and use your own app/release.jks if you publish the app.
